VIGIlance is ARCenal's employee-management application, powered by ARCenal OS.

This preview increment provides professional employee dossiers, personal dossier access, explicit application roles and a Gratitude-themed interface. The enterprise logo is read from the main YunoHost domain. YunoHost SSO authenticates users; direct LDAP group synchronization is a subsequent increment and is not claimed by this package.

The historical app identifier `arcenalportail` is preserved. Application data and private settings stay outside the public web root; the package includes versioned schema setup, consistent SQLite snapshots and backup/restore scripts.

The candidate/onboarding workflows, document vault and future Dolibarr indicator export remain subsequent increments. A packaging qualification does not constitute customer acceptance of these business workflows.
