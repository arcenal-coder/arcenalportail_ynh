*[Lire ce README en français.](./README_fr.md)*

> This package installs the ARCenal employee QSSE portal on a YunoHost server.

## Overview

ARCenal Portail gives employees an interface for MAT briefings, field reports and assigned PAO actions. YunoHost SSO/LDAP authenticates the user. Signed HTTPS requests connect the portal to the ARCenal QSSE module for Dolibarr.

**Shipped version:** 0.4.2~beta1+ynh1

## Configuration

The installer asks for the public HTTPS gateway URL generated by ARCenal QSSE and its 64-character pairing key. The connected Dolibarr module remains a separate requirement.
